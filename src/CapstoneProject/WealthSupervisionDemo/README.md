# WealthSupervisionDemo — .NET Blazor Server + Microsoft Foundry Agent Framework

## Quick Start in Visual Studio 2022 / 2025
1. Extract this ZIP archive to `C:\Faisal\Development\Capstone Project AMA\WealthSupervisionDemo`.
2. Double-click `WealthSupervisionDemo.csproj` to open the project directly in Visual Studio.
3. Visual Studio automatically restores NuGet packages (`Azure.AI.Projects`, `Azure.Identity`, `Microsoft.Agents.AI.Foundry`, `Microsoft.Agents.AI.Workflows`).
4. Press **F5** to run.
5. By default, `Foundry:UseMockMode` is `true` in `appsettings.json` for zero-Wi-Fi-risk live demos. Enter your `ProjectEndpoint` (and optional `ApiKey`) in `appsettings.json` and flip the header toggle in the UI to switch to **LIVE MICROSOFT FOUNDRY**.
